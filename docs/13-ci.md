# Continuous Integration

Every push and pull request targeting `main` now runs:

```text
pnpm test
pnpm typecheck
pnpm build
```

The workflow uses Node.js 22 and pnpm 10.17.1.

The repository still needs a committed `pnpm-lock.yaml`. Until that file is generated from a real development checkout, CI uses:

```bash
pnpm install --no-frozen-lockfile
```

Once the lockfile is committed this should be changed to `pnpm install --frozen-lockfile`.
