# MCP 管理列表

## 拖拽排序

- 每项左侧的手柄支持纵向拖拽，绿色指示线表示放在目标项之前或之后。
- 松开手柄后应用排序并保存；拖到列表外、按 Escape 或指针操作取消时不提交排序。
- 聚焦手柄后可用上下方向键调整顺序；仅一个项目时手柄禁用。
- 排序只影响 MCP 管理列表的显示，不修改 Server 配置、连接状态、Profile 或启动顺序。

## 本机保存

顺序按 Server id 保存于当前 WebView origin 的 `localStorage`：

```text
mcp-gate.server-display-order.v1
```

刷新和正常重启后读取保存顺序；已删除 id 被忽略，新项目追加到末尾。
非法存储内容按默认顺序处理。写入失败会显示提示，本次界面顺序仍会更新，
但重启后可能丢失。

显示顺序不写入 `servers.json`，不属于 Core 配置备份，也不在不同设备、浏览器、
开发态与安装版 WebView origin 之间同步。清理 WebView 存储会重置顺序。

## 长内容

- 命令和 HTTP URL 单行省略显示，悬停可查看完整文本。
- 长名称省略，状态标记保留；工作目录可换行并提供完整悬停提示。
- 列表使用受限宽度网格，避免长命令将卡片和操作按钮撑出容器。

## 验证

`npm run test:desktop` 检查排序存储解析、刷新后排序、新增/删除项目处理、
前后插入以及无效移动。整体 `npm test` 包含这些测试。
拖拽、键盘、刷新保留和长命令布局另经浏览器中的实际 React 组件验证；
这些交互检查目前不是 CI 自动化用例。
